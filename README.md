## 🚀 Featured projects

### [Mini Cloud Platform](https://github.com/andersna/MiniCloudPlatform)
A self-hosted platform in Go for deploying and managing containerised applications directly from Git repositories.
- REST and gRPC APIs, PostgreSQL persistence and application lifecycle management
- CLI client and a custom Terraform provider for automated deployment
- Automatic recovery, logging and monitoring with Prometheus and Grafana

`Go` `Docker` `PostgreSQL` `gRPC` `Terraform` `Prometheus` `Grafana`

### [MatchHubML](https://github.com/andersna/MatchHubML) · [Live demo](https://andersna.github.io/MatchHubML/)
An end-to-end machine learning system that predicts football match outcomes across Europe's five major leagues and compares the model against market probabilities.
- Data pipeline with feature engineering and safeguards against data leakage
- Models evaluated with chronological walk-forward backtesting and log loss
- Scheduled pipeline generates JSON snapshots that power a static dashboard on GitHub Pages

`Python` `PyTorch` `FastAPI` `SQLite`

### [MatchHub](https://github.com/andersna/MatchHub)
A full-stack football data platform for collecting, processing and presenting match, team and statistics data.
- REST APIs with service and repository layers, integration with Sportmonks
- Event-driven communication between components with Kafka, caching with Redis
- Containerised with Docker Compose and monitored with Prometheus and Grafana

`C#` `.NET` `React` `Kafka` `Redis` `Docker`
